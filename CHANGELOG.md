# Changelog

## 1.0.1 - 2026-10-21

- Several results can be selected with Shift or Command and deleted together, from the context menu, the Delete key or the selection view; deleting more than one asks first
- Clicking anywhere outside the comment field ends editing; the field is no longer focused at launch
- macOS 26 and later: the window uses the Liquid Glass look in every build, with separate toolbar capsules and notices as cards under the toolbar
- Settings tabs no longer collapse into one truncated button on macOS 26 and later

## 1.0.0 - 2026-10-08

First release.

- Frame time capture from the Metal Performance HUD, either through the system log (any game, with the logging profile installed) or from a game launched by MetalCap
- AVG, P1, 1% Low (Average or Integral), 0.1% Low and other percentiles, calculated as in CapFrameX
- Global start/stop shortcut with sounds, menu bar item
- Frame time chart and system metrics with a shared pointer: GPU load and memory, CPU and GPU temperature, CPU/GPU/whole-Mac power, CPU cluster activity and clocks, GPU clock, fan speed, game CPU and memory, thermal state
- Hardware, game window size and Game Mode saved with every result
- Comments, renaming (also for every result of a game) and sorting
- Export: full result as JSON, frames and system metrics as CSV, summary of all results as CSV
- Metal HUD overlay settings: metrics, position, scale, opacity
- English and Polish interface
